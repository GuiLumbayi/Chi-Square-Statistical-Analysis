# Categorical Data Analysis: Chi-Square Testing in R

## 📌 Project Overview
This repository contains a comprehensive analysis of categorical data distributions using Chi-Square frameworks in R. The project evaluates three structural problem types: evaluating associations between independent groupings, analyzing population dynamics across multiple tiers, and testing uniform theoretical fit parameters.

## 📊 Methods & Applications Covered
* **Chi-Square Test of Independence:** Examined interactions between biological sex and political party affiliations.
* **Contingency Tables & Matrix Operations:** Built multi-tier arrays mapping education levels against scientific belief systems.
* **Goodness-of-Fit Tests:** Checked observation distributions against uniform probabilities utilizing category-level counts.

## 📁 Repository Structure
* `chi_square_analysis.R`: The complete production script containing manual matrices, test execution blocks, and automated annotation comments.
* `_Chi_Square_Methods_Report(GL).pdf`: My final submitted academic report detailing hypotheses, calculations, p-values, and written analytical interpretations.
